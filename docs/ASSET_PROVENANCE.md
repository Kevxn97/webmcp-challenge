# Asset provenance

The visual assets in Agentic Sandbox contain no stock photography, licensed music or video, customer data, third-party logos, trademarked product branding, or production-system exports. Product and company names in the documentation are nominative technical references only.

## Project-created visual assets

| Asset | Origin | Use |
| --- | --- | --- |
| `src/assets/drafting-grid.png` | Generated specifically for Agentic Sandbox with OpenAI image generation, then selected and integrated during the design process. | Low-contrast paper and drafting-grid texture behind the interface. |
| `docs/visual-target-precision-blueprint.png` | Project-specific OpenAI-generated visual direction supplied during development. | Design reference only; it is not shipped in the runtime bundle. |
| `docs/agentic-sandbox-desktop.png` | Screenshot rendered from the application at the documented reference viewport. | README and visual QA evidence. |
| `docs/design-comparison*.png` | Comparisons assembled from the project-specific visual target and application screenshots. | Visual QA evidence only. |

The generated images contain no recognizable people, logos, third-party characters, or copied product interfaces.
